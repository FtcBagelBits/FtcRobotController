# Pollen documentation

Use these documents with the code installed on the robot.

| Document | Audience and purpose |
| --- | --- |
| [Operating manual](POLLEN_AUTONOMOUS.md) | Drivers and students: choose a routine, position the robot, use INIT controls, interpret warnings and record tested settings. |
| [Code README](../TeamCode/src/main/java/org/firstinspires/ftc/teamcode/pollen/README.md) | Programmers: file map, hardware, sequencing, calibration, tests and deployment. |
| [How autonomous works](POLLEN_AUTONOMOUS_EXPLAINED.md) | Students: hardware names, lifecycle, timed movement, shooting and failure handling. |
| [Field routes](POLLEN_FIELD_ROUTES.md) and [diagram](POLLEN_FIELD_ROUTES.svg) | Programmers and drive team: CAD geometry, presets, clearances, parking margins. |
| [Pit sheet](POLLEN_PIT_SHEET.svg) | Alliance partners: lanes, parking slots, timing and setup rules on one printable page. |

Menu controls belong in the operating manual. Implementation details belong in
the code README. Update documentation with behavior changes, and record the
installed commit with physical test results.
